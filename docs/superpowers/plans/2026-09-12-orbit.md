# Orbital Survival Implementation Plan

**Goal:** Playable keyboard-controlled gravity survival prototype.
**Architecture:** Pure simulation in src/physics.js; Three.js view in src/view.js; input, lifecycle and HUD in src/main.js.
**Tech Stack:** JavaScript ES modules, Three.js, Vite, Node test runner.
**Spec:** docs/superpowers/specs/2026-09-12-orbit-design.md

1. Write and run physics tests before implementation: inverse-square attraction, inertial coast, thrust and steering, randomized safe launches, swept collision, boundary death, fixed-step consistency.
2. Implement simulation exports createRun(random), gravity(ship,bodies), step(state,input,dt), advance(state,input,elapsed), and sweptHit(a,b,r). Run `npm test`.
3. Build orthographic scene with orbit rings, planetary spheres, star glow, ship, exhaust and trail. Build responsive HTML HUD with start, pause, restart, elapsed time and best score.
4. Install dependencies, run `npm test` and `npm run build`, start local server and inspect browser. Document launch instructions and tuning constants.
