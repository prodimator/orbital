# Orbital Mobile Play Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Orbital playable on phones and tablets in landscape, with touch controls, a zoomed follow camera, and a compact HUD.

**Architecture:** Three new pure modules (`camera.js`, `mode.js`, and the helpers in `touch.js`) carry all the logic worth testing; DOM wiring stays thin and lives in `touch.js`, `orientation.js` and `main.js`. The camera becomes a clamped follow camera driven by a pure framing function. Touch input is an adapter that produces the same `{left, right, up, shoot}` booleans the keyboard already produces.

**Tech Stack:** JavaScript ES modules, Three.js 0.186, Vite 8, Node built-in test runner (`node --test`). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-12-mobile-design.md`

## Global Constraints

- **The simulation must not change.** `src/physics.js`, `src/projectiles.js`, `src/asteroids.js` and `src/scoring.js` are not edited by any task. The six existing test files are the regression check and must stay green after every task.
- **No new dependencies.** Do not add packages to `package.json`.
- Run `npm test` before every commit. It must pass.
- Code style follows the existing source: ES modules, dense single-line statements, semicolons, minimal comments reserved for non-obvious reasoning.
- Camera constants, copied verbatim from the spec: base extent `1020`, compact zoom `2.2`, desktop zoom `1`, `bound = LIMIT + 60`, camera smoothing `1 - Math.exp(-elapsed / 0.12)`.
- Touch constants, copied verbatim from the spec: stick deflection below `0.25` produces no steering.
- HUD panel width in compact mode is `116px`, declared once as the CSS custom property `--hud-width` and read from CSS by JS. Never hardcode `116` in JavaScript.

export const BASE_EXTENT = 1020;
// The followed point is clamped against the USABLE viewport (the part not covered by the HUD),
// then shifted left by half the panel. Clamping the whole frustum first would discard the shift
// on any axis wide enough to lock, which is exactly the phone case.
function clampAxis(value,half,bound){const range=bound-half;return range>0?Math.max(-range,Math.min(range,value)):0;}
export function frame({shipX=0,shipY=0,width,height,zoom=1,hudPx=0,bound=Infinity}){
 const aspect=width/height;
 const halfH=BASE_EXTENT/Math.min(1,aspect)/zoom;
 const halfW=halfH*aspect;
 const offset=hudPx*halfH/height;
 return {halfW,halfH,cx:clampAxis(shipX,halfW-offset,bound)-offset,cy:clampAxis(shipY,halfH,bound)};
}
```

// Compact mode is a LAYOUT decision, resolved from input-capability media queries at load.
// Device sniffing is deliberately avoided: iPadOS Safari reports itself as macOS, and
// navigator.userAgentData.mobile exists only in Chromium.
export function resolveCompact({coarse,hoverless,override}){return override===null||override===undefined?coarse&&hoverless:override;}
export function readOverride(search){const value=new URLSearchParams(search).get('touch');return value==='1'?true:value==='0'?false:null;}
export function watchCompact(override,onChange){
 const coarse=matchMedia('(pointer: coarse)'),hoverless=matchMedia('(hover: none)');
 const apply=()=>onChange(resolveCompact({coarse:coarse.matches,hoverless:hoverless.matches,override}));
 coarse.addEventListener('change',apply);hoverless.addEventListener('change',apply);apply();
}
// Control visibility is an INPUT decision, observed rather than predicted. Browsers emit
// compatibility mouse events after a touch, so a recent touch suppresses the mouse path.
export function watchTouch(onChange){
 let lastTouch=0;
 addEventListener('pointerdown',e=>{if(e.pointerType==='touch'){lastTouch=performance.now();onChange(true);}},{capture:true});
 addEventListener('mousemove',()=>{if(performance.now()-lastTouch>1000)onChange(false);},{capture:true});
}
```

- [ ] **Step 3: Write the implementation**

Create `src/touch.js`:

```js
export const DEADZONE = 0.06;
export const MIN_DEFLECTION = 0.25;
export function wrapAngle(a){return Math.atan2(Math.sin(a),Math.cos(a));}
// Screen Y grows downward; world Y grows up. dy is inverted once, here, and nowhere else.
export function stickVector(origin,point,radius){
 const dx=point.x-origin.x,dy=origin.y-point.y,distance=Math.hypot(dx,dy);
 if(!distance)return {angle:0,deflection:0,x:0,y:0};
 const deflection=Math.min(1,distance/radius);
 return {angle:Math.atan2(dy,dx),deflection,x:dx/distance*deflection,y:dy/distance*deflection};
}
// physics.js applies (left - right) * TURN * dt, so left increases the angle.
export function steerToward(current,target,deadzone=DEADZONE){
 const diff=wrapAngle(target-current);
 return {left:diff>deadzone,right:diff<-deadzone};
}
export function aimInput(stick,current){
 return stick&&stick.deflection>=MIN_DEFLECTION?steerToward(current,stick.angle):{left:false,right:false};
}
```
